Local data & backup
On this device

          
Your workouts and goals are saved in this browser using localStorage. They are not uploaded to GitHub or synced automatically to another device.

          

            
            
            
            
          

          
Keep a backup if you clear Safari website data, switch browsers, or change devices. Importing a backup replaces the data currently stored in this app.

          
Clear all app data

          
This permanently removes saved workouts and goals from this browser. Export a backup first if you may need it later.

          
        

        

          
Scheduled email reports
Setup needed

          
The app can prepare weekly and monthly summaries, but a local HTML page cannot reliably run in the background or send email by itself.

          
To automate sending later

          

            
1
Choose a schedulerFor example, a scheduled workflow or automation service.

            
2
Provide data securelyLocal-only data is not available to a cloud scheduler unless you deliberately export or sync it.

            
3
Connect email deliveryUse an email provider or service with credentials stored securely outside the HTML file.

          

          
Never put email passwords, private API keys, or service credentials in a public HTML file or GitHub repository.
